# Stream D2: chord dropdown and chip row

Format: **date — decision.** Why. _Rejected:_ alternatives.

- **2026-10-07 — `ChordDropdown.svelte` stays the region root** (`id="chords"`, labeled "Chords") and holds both the chip row (`ChordChipRow.svelte`) and the dropdown. `App.svelte` imports only this component, and the dropdown has to be opened from both the staff (`onNoteClick`) and the chips, so the open state lives in one place. _Rejected:_ a separate popover component that the chip row and region each talk to (a second channel for "open at this note").
- **2026-10-07 — Pure helpers sit beside the components:** `options.js` (candidates ordered by `fit`, the "why" label from `analyzeNoteOverChord`, number key to degree), `passage.js` (the bar around a note and the voicing inputs), and `chordView.js` (label in the user's style, function, shape, accessible name, by key-label mode). They compose theory functions and compute no theory of their own. _Rejected:_ computing these inline in the components (the PRD forbids theory in components).
- **2026-10-07 — The audition range is the bar the note starts in, stretched to the note's end** when it is held across the bar line. Bar 0 is the pickup (0 to `pickupTicks`). Comes from `rebar`, so it follows the current meter hypothesis.
- **2026-10-07 — Every candidate for a note shares one voicing context:** `below` is the lowest melody note sounding in that bar, and `previous` is the voicing of the nearest chord placed before the note (voiced with no previous of its own). A and B therefore differ only in harmony, as the PRD's audition rule requires. _Rejected:_ chaining voice leading back through every earlier chord (slower, and the audio stream voices the other chords itself).
- **2026-10-07 — No pre-selection; ties keep the theory core's order.** Options sort by `fit` descending with a stable sort, and opening the dropdown focuses the dialog, not an option, so no chord sounds or lights until the user moves.
- **2026-10-07 — Number keys focus the option for that degree** (1–7, no modifiers, read from `KeyboardEvent.code`), and focus auditions it, so the next Enter commits what was just heard. Pressing the same number again re-auditions. Only diatonic roots in the likely list answer to a number; degrees with no candidate (vii in major, ii and vii in minor) do nothing. The handler calls `stopPropagation` so the number row doesn't also play a melody note (see the contract request below).
- **2026-10-07 — Arrow Up/Down move between the dropdown's buttons; Tab works too.** Tabbing out, or a pointer press outside, closes the dropdown without restoring focus (the user is going somewhere). Escape closes and returns focus to the opener (the chip, or whatever had focus when the staff note was clicked). Closing without choosing stops an audition this dropdown started; choosing lets it ring.
- **2026-10-07 — Keyboard lights follow the hovered option, else the focused one,** and show the candidate's voicing in its function color plus the melody note as a neutral highlight. In hidden mode the color is `other`, so the keyboard doesn't reveal function. The dropdown clears `ui.keyboardLights` only if it set them, so it never wipes the transport's lights.
- **2026-10-07 — Hidden mode shows letter names only.** Letter names are not key-relative; numerals, Nashville numbers, function colors and shapes, and the function name in the accessible label are all withheld. Tentative chips are outlined (dashed edge, unfilled shape at `--tentative-opacity`); confirmed chips are filled with the function's soft color and a solid shape, and the change animates over `--dur-reveal` (zero under reduced motion).
- **2026-10-07 — Chip design: soft function background, solid function shape, `--ink` text.** Text never sits on a saturated fill, so every function, including yellow, keeps AA contrast without a per-function text token, and yellow takes `--fn-subdominant-edge` as its outline per the PRD. _Rejected:_ saturated fills with `-ink` text (the shape would vanish into its own fill).
- **2026-10-07 — Nashville sevenths render as a superscript `7`** (`nashvilleOf` returns a plain 7; the view raises it). `maj7` stays inline, per the PRD's notation list.
- **2026-10-07 — Tutor suggestions show in two places, never applied.** In the chip row, each suggestion is a dashed card with "Hear it" (audition at its note) and "Compare" (opens the dropdown on that note). In the dropdown they form a "From the tutor" group with confidence and reason, and choosing one is the only way it reaches the song. Labels re-derive from the suggested chord and the current key rather than trusting the tutor's numeral, so a re-key relabels them. Stale sets (`isStale`) carry a visible note and a dotted outline. Suggestions whose note no longer exists are counted ("one idea was for a note that's no longer there"), never re-anchored.
- **2026-10-07 — "No chord here" removes a placed chord** (`song.setChord(noteId, null)`). Placing a chord without a way to take it back would leave only undo, and the PRD says the dropdown both places and changes chords.
- **2026-10-07 — "Something else…" is a disclosure button** (`aria-expanded`) that reveals the extended candidates below it, deduplicated against the likely list and ordered by fit. Keeping the button in place keeps focus inside the dropdown. _Rejected:_ replacing the button with the list (focus would fall to the page body and keyboard handling would stop).
- **2026-10-07 — Audio status in the dropdown:** loading shows "Loading piano sounds…"; failed shows an alert with "Try again", which calls `preload()` and reports a rejection in place. The dropdown doesn't call `unlock()`: unlocking plays the sound-check chord, which belongs to the landing screen.
- **2026-10-07 — The dropdown is absolutely positioned in page coordinates** below the anchor rect, clamped inside a 16px gutter, so it scrolls with the staff. Max height 70vh with its own scroll.

## Deviations and contract requests

- **No unit tests in this stream.** The brief limits tests to theory and backend; D2 adds no theory. The helpers in `src/chords/*.js` are pure and were exercised by hand against both demo songs.
- **Contract request: the number row must yield while the dropdown is open.** D2 stops propagation of Digit1–7 at the dropdown, which covers listeners on `window` or `document` in the bubble phase. If D1 listens in the capture phase, it needs a shared signal (for example a `ui.chordDropdownOpen` flag) to skip note keys.
