# Stream T: toolbar decisions

Format: **date — decision.** Why. _Rejected:_ alternatives.

- **2026-10-07 — `song.transpose(semitones, { prefer })` passes the enharmonic preference straight to theory's `transposeSong`.** The key picker offers both F# and Gb major (and D# and Eb minor), and only `prefer` tells the theory core which name to give the new tonic. Without an option the store behaves as before. _Rejected:_ a separate `transposeTo(tonic)` store action (a second way to transpose, and it would duplicate the octave logic the toolbar owns).
- **2026-10-07 — The transpose picker is a row of one-click key buttons for the song's current mode,** with the current key pressed. The PRD asks for one-click transposition; a `<select>` that transposes on change fires on arrow keys in some browsers, filling the undo history with every key the user scrolls past. Transpose keeps the mode, so only that mode's keys are offered. _Rejected:_ a select plus a "Transpose" button (two clicks); offering both modes (changing mode is re-keying, not transposing).
- **2026-10-07 — Each key button's `prefer` comes from its own spelling** (`#` asks for sharps, `b` for flats, a natural needs none). A test transposes to every offered key in both modes and checks the result is named as the button says, so B major never comes out as Cb and G# minor never as Ab minor. _Rejected:_ a hand-written prefer per key (26 entries to keep in sync).
- **2026-10-07 — The octave is the nearest move, up or down, that keeps every melody note in C2 to C6,** trying ±0–11 semitones first, then the next octave out. If nothing fits (a melody wider than the keyboard), it takes the nearest move anyway. Ties (a tritone) go up.
- **2026-10-07 — Picking the enharmonic twin of the current key (F# to Gb) re-spells through `song.rekey`, keeping `provisional` as it was.** `transposeSong` by 0 semitones keeps the tonic's spelling by design, so it can't rename the key. Re-keying to the twin is the theory core's respelling path: no note moves and every numeral stays the same, which is what transpose promises. This is the one place the transpose control calls `rekey`. _Rejected:_ disabling the twin button (the user asked for that spelling; F# and Gb read differently on the staff).
- **2026-10-07 — Deviation from the brief: transpose's key buttons are also disabled while a demo awaits its first guess** (hidden mode), with a one-line reason. The brief disables only re-key. Hidden mode shows the provisional C, so "Now in C major" would be false, and transposing would move the tune away from the true key in the demo's content file that D3's drone test plays against. The octave buttons stay on: they keep the tonic. _Rejected:_ leaving transpose on in hidden mode.
- **2026-10-07 — Octave buttons are disabled with an empty melody,** since there is nothing to move.
- **2026-10-07 — Re-key is one select of all offered keys, grouped Major and Minor, plus a "Set home" button,** in a dashed-border group worded "Home is actually…". One select avoids a tonic that doesn't exist in the other mode (Db minor) when the mode changes. "Set home" stays enabled for the current key while it is provisional, so a user can confirm the provisional C. The select follows the song's key until the user picks another (a writable `$derived`).
- **2026-10-07 — The toolbar imports `Note.chroma` from Tonal** to compare tonics by pitch class. Theory's `chromaOf` isn't exported from `src/theory/index.js`; see the contract request.
- **2026-10-07 — Undo shortcuts listen on the window and skip text inputs, textareas, and editable content,** so the tutor's text box keeps its own undo. Presses with Alt/Option are ignored, so only Cmd/Ctrl-Z and Shift-Cmd/Ctrl-Z act. Checkboxes, radios, buttons, and selects aren't text fields, so the shortcut works with focus on toolbar controls. The pure parts (`historyShortcut`, the key and octave math) have unit tests under `tests/toolbar/`, as decision D6 allows.
- **2026-10-07 — Plain-language hints sit under each group heading:** transpose, "The whole tune moves higher or lower. Every number stays the same."; re-key, "The notes stay exactly as you hear them. Only home moves, so the numbers and colors change." Matthew's to rewrite.
