# Stream B (audio): decisions

Format: **date — decision.** Why. _Rejected:_ alternatives.

- **2026-10-07 — Salamander Grand Piano (Alexander Holm, CC BY 3.0), 17 samples every minor third from C2 to C6, cut to 4 s with a 1 s fade.** CC BY allows redistribution with attribution; the set is already sampled in minor thirds, so `Tone.Sampler` never repitches more than a semitone and a half. Trimming takes it from 1.3 MB to about 0.5 MB, and no note in a phrase or audition rings longer than 4 s. Source, licence, and the exact ffmpeg command are in `public/samples/piano/SOURCES.md`. _Rejected:_ a Tone synth (sounds like a toy, and the PRD asks for samples); every semitone (three times the download for little gain); hotlinking Tone's CDN copy (the CSP is `'self'`, and the app would depend on someone else's host).
- **2026-10-07 — Tone's default context is the one AudioContext.** Importing Tone creates its default context (latencyHint `"interactive"` is Tone's default), so building a second `Tone.Context` would briefly make two. The engine sets `lookAhead` on the default one instead.
- **2026-10-07 — Zero look-ahead for live notes, 50 ms for scheduled playback.** Live notes trigger at `Tone.immediate()` (the raw audio clock, no look-ahead). The Transport keeps a 50 ms look-ahead so phrases never glitch, and `Tone.Draw` lines the visuals up with the sound. This matches the PRD's "zero look-ahead for live key presses" literally rather than setting the context's look-ahead to 0, which would make Transport playback late and jittery. 50 ms rather than Tone's 100 ms keeps hover audition quick.
- **2026-10-07 — Tone is imported on first use** (`preload`, `unlock`, or any sound), so it stays out of the first-paint bundle. Creating the context before a gesture is allowed; it starts suspended until `unlock` (or the first key press) resumes it.
- **2026-10-07 — Two samplers on the same decoded buffers:** one for live notes, one for playback. `stop()` and each new playback release the playback sampler without cutting a key the user is holding. `stop()` itself, which the contract says stops everything, releases both.
- **2026-10-07 — Failures never throw; `audioStatus` carries them, and `preload()` after `failed` is the retry.** The contract has no `retry` export, and a rejected promise from a hover handler would be easy to drop. Each failure is logged with `console.error` and resets the loader so the next call tries again. Playback functions resolve at once (with an `end` event) when samples are unavailable, so callers never hang.
- **2026-10-07 — The drone and click are plain `Tone.Synth`s, not piano samples.** A drone has to sustain until released, and piano samples decay; the click must be short and distinct from the tune. Both work even if the samples failed.
- **2026-10-07 — Every playback (phrase, audition, click test) goes through the one Transport and stops the one before; the drone is independent.** The drone test holds a tonic under phrase playback, so starting a phrase must not stop it. A request counter means a playback still waiting on `wake()` never starts after `stop()` or a newer request.
- **2026-10-07 — Passage rules, in `src/audio/passage.js`:** melody notes that start in the range play, clipped to its end; the chord already sounding at `fromTick` comes in on the first tick; each chord holds until the next chord or the range end; chords without a given voicing are voiced in order with `voice(chord, previous, { below })`, where `below` is the passage's lowest melody note (middle C if the passage has no notes). The audition candidate replaces the chord whose note starts at `atTick`, or is added there if none does, and the chord after it voice-leads from the candidate. `playPhrase`'s `chords` option replaces all of the song's chords and uses the voicings given.
- **2026-10-07 — The click sounds every beat unit and accents only downbeats,** counted from the first downbeat after the pickup: a pickup clicks unaccented, and 6/8 clicks six eighths with the accent on the first. _Rejected:_ a secondary accent on beat 4 of 6/8 (not asked for; the test is "where is beat 1").
- **2026-10-07 — `playWithClick` plays the melody and the click, no chords,** as the contract describes ("the melody over a click"); chords landing on beat 1 would bias the meter test.
- **2026-10-07 — `onEvent` also gets `end` when playback is stopped,** not only when it finishes, so the transport can always clear highlights.
- **2026-10-07 — Verified in Chrome** against a temporary harness (not committed) under a CSP meta tag matching production's `script-src 'self'` and `worker-src 'self' blob:`: samples load, the sound check plays, phrase events arrive on the beat at the song's tempo, audition, click, drone, and stop all run, with no CSP or worklet errors.
