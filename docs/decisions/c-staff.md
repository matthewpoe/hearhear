# Stream C: staff, transport, and export

Format: **date — decision.** Why. _Rejected:_ alternatives.

- **2026-10-07 — The known risk is solved: chord symbols are colored after rendering, through abcjs's own object model.** abcjs can't style one chord symbol from ABC. After `renderAbc`, each drawn note's `abselem` keeps its chord symbol as a child of type `"chord"` with its SVG `graphelem`. Drawn notes come out in the order `songToAbc` wrote them, so the nth drawn note (rests excluded) is the nth note piece, which carries the note id and chord id (`src/staff/noteMap.js`). A count mismatch throws and the staff shows an error rather than mislabeling. Proven in the browser on both demo tunes, in both themes and all three label modes. _Rejected:_ matching by `startChar` (it points at the chord string before the note, and is fragile to edits of the ABC writer); matching SVG text by content (two chords can share a name).
- **2026-10-07 — Chord symbols get a chip with the function's shape, not only colored text.** A rounded rect behind the letter name and a small circle, triangle, or square at its left, so the staff never relies on color alone (PRD accessibility). Confirmed: filled with `--fn-*` and `--fn-*-ink` text (yellow gets the `--fn-subdominant-edge` outline). Tentative: outline only, `--tentative-stroke` and `--tentative-opacity`, text in `--ink`. "Other" chords get a gray chip with no shape. This is the lead sheet's chord symbol, not a second chip row: D2 owns the chip row. _Rejected:_ colored text only (yellow text fails contrast; color alone).
- **2026-10-07 — The staff redraws when the song changes or when the notation itself changes (label mode, label style, degree toggle).** Those view settings change what abcjs lays out (key signature, annotations, lyric line), so they can't be a class toggle. Playhead, hover, and selection never redraw. **Deviation from the brief's "only when the song's version changes."** Tentative ↔ confirmed only restyles chips through a container class, but in practice it always comes with a re-key, which bumps the version. _Rejected:_ drawing every label and hiding them with CSS (hidden mode must not draw a key signature, and hidden text in the SVG would still be read by screen readers).
- **2026-10-07 — Hidden mode writes `K:C` and computes accidentals per bar.** The ABC writer tracks the accidental in force for each letter and octave in a bar (key signature first, then earlier notes), writing `^`, `_`, or `=` only when it changes, so the same code serves real key signatures and the hidden C. Letter-name chord symbols still show in hidden mode (they aren't key-relative); numerals, degrees, and chips don't, and note names in the accessible labels drop degrees and numerals too.
- **2026-10-07 — Durations: `L:1/48`, so an ABC length is a tick count.** Notes split at bar lines and into drawable lengths (dotted whole down to sixteenth), joined by ties; only the first piece carries the chord and degree (later pieces get `*` on the lyric line). Short notes in the same beat are beamed. Triplet lengths are written as-is and abcjs approximates them; no demo tune uses them yet. _Rejected:_ writing tuplets now (outside the golden path).
- **2026-10-07 — Numerals below the staff are abcjs annotations; Nashville sevenths are superscripted with "⁷".** `letters` style shows no numeral; `roman+letters` shows the Roman numeral (letters are already above). Degrees use combining dots (U+0307 above, U+0323 below, one per octave) with ♯/♭ before the number.
- **2026-10-07 — Notes are keyboard buttons with one tab stop.** Each note's first SVG group gets `role="button"`, an accessible name ("F sharp 4, degree 3, chord D (I)"), and a roving tabindex: Left/Right/Home/End move between notes, Enter or Space opens the dropdown via `emitNoteClick`. The SVG's `role="img"` from abcjs is changed to `group` so the buttons are exposed. Up/Down are left alone (D1 uses them for octaves).
- **2026-10-07 — The reveal uses the Web Animations API, reading `--dur-reveal` and `--ease` from the tokens.** It runs when the label mode becomes confirmed: chips grow in and numerals and degrees fade in. Under prefers-reduced-motion the token is 0 ms and nothing animates. WAAPI needs no style attributes or `<style>` injection, so the CSP is untouched. _Rejected:_ a CSS class with `animationend` cleanup (no event at 0 ms).
- **2026-10-07 — The transport is one toggle button (Play/Stop)** so focus stays put when playback starts. It plays the whole song, lights the current note with `is-playing`, sets `ui.playheadNoteId`, and writes `ui.keyboardLights`: the melody note, and the latest chord's tones with its function, kept until the next chord. In hidden mode the chord's function is sent as `"other"` so the keyboard can't reveal the key. Sample loading, failed samples (Retry calls `preload`), and failed playback (Try again) each show a status line.
- **2026-10-07 — The print stylesheet is imported by `Staff.svelte`,** since `App.svelte` and `main.js` are outside this stream. In print it hides everything but the staff (masthead, footer, every other region, the toolbar) and keeps the chip colors with `print-color-adjust: exact`. Print uses the light tokens because the dark theme applies only on screen.
- **2026-10-07 — No unit tests for the ABC writer.** The brief limits tests to `tests/theory/` and the backend, and `tests/` isn't this stream's path. The writer was checked by script against both demo tunes (parsed note count equals note pieces, no abcjs warnings) and in the browser. Proposed as an addition.
