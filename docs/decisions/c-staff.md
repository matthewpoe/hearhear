# Stream C: staff, transport, and export

Format: **date — decision.** Why. _Rejected:_ alternatives.

- **2026-10-07 — The known risk is solved: chord symbols are colored after rendering, through abcjs's own object model.** abcjs can't style one chord symbol from ABC. After `renderAbc`, each drawn note's `abselem` keeps its chord symbol as a child of type `"chord"` with its SVG `graphelem`. Drawn notes come out in the order `songToAbc` wrote them, so the nth drawn note (rests excluded) is the nth note piece, which carries the note id and chord id (`src/staff/noteMap.js`). A count mismatch throws and the staff shows an error rather than mislabeling. Proven in the browser on both demo tunes, in both themes and all three label modes. _Rejected:_ matching by `startChar` (it points at the chord string before the note, and is fragile to edits of the ABC writer); matching SVG text by content (two chords can share a name).
- **2026-10-07 — Chord symbols get a chip with the function's shape, not only colored text.** _Superseded by D3 (see Wave-1 fixes): the staff now shows colored letter names only._ A rounded rect behind the letter name and a small circle, triangle, or square at its left, so the staff never relies on color alone (PRD accessibility). Confirmed: filled with `--fn-*` and `--fn-*-ink` text (yellow gets the `--fn-subdominant-edge` outline). Tentative: outline only, `--tentative-stroke` and `--tentative-opacity`, text in `--ink`. "Other" chords get a gray chip with no shape. This is the lead sheet's chord symbol, not a second chip row: D2 owns the chip row. _Rejected:_ colored text only (yellow text fails contrast; color alone).
- **2026-10-07 — The staff redraws when the song changes or when the notation itself changes (label mode, label style, degree toggle).** Those view settings change what abcjs lays out (key signature, annotations, lyric line), so they can't be a class toggle. Playhead, hover, and selection never redraw. **Deviation from the brief's "only when the song's version changes."** Tentative ↔ confirmed only restyles chips through a container class, but in practice it always comes with a re-key, which bumps the version. _Rejected:_ drawing every label and hiding them with CSS (hidden mode must not draw a key signature, and hidden text in the SVG would still be read by screen readers).
- **2026-10-07 — Hidden mode writes `K:C` and computes accidentals per bar.** The ABC writer tracks the accidental in force for each letter and octave in a bar (key signature first, then earlier notes), writing `^`, `_`, or `=` only when it changes, so the same code serves real key signatures and the hidden C. _(Superseded by D2: hidden mode now shows a neutral mark, not the letter name.)_ Letter-name chord symbols still show in hidden mode (they aren't key-relative); numerals, degrees, and chips don't, and note names in the accessible labels drop degrees and numerals too.
- **2026-10-07 — Durations: `L:1/48`, so an ABC length is a tick count.** Notes split at bar lines and into drawable lengths (dotted whole down to sixteenth), joined by ties; only the first piece carries the chord and degree (later pieces get `*` on the lyric line). Short notes in the same beat are beamed. _Corrected in wave 1:_ the split is greedy, so a triplet length is not approximated: a 4-tick triplet eighth becomes a dotted sixteenth tied to a 1/48, which abcjs can't draw cleanly. No demo tune uses triplets yet; real tuplets (`(3`) are wave 2.
- **2026-10-07 — Numerals below the staff are abcjs annotations;** _Superseded by D3: the staff no longer writes numerals; they live in D2's chip row. Degrees are unchanged._ Nashville sevenths are superscripted with "⁷".** `letters` style shows no numeral; `roman+letters` shows the Roman numeral (letters are already above). Degrees use combining dots (U+0307 above, U+0323 below, one per octave) with ♯/♭ before the number.
- **2026-10-07 — Notes are keyboard buttons with one tab stop.** Each note's first SVG group gets `role="button"`, an accessible name ("F sharp 4, degree 3, chord D (I)"), and a roving tabindex: Left/Right/Home/End move between notes, Enter or Space opens the dropdown via `emitNoteClick`. The SVG's `role="img"` from abcjs is changed to `group` so the buttons are exposed. Up/Down are left alone (D1 uses them for octaves).
- **2026-10-07 — The reveal uses the Web Animations API, reading `--dur-reveal` and `--ease` from the tokens.** It runs when the label mode becomes confirmed: chips grow in and numerals and degrees fade in. Under prefers-reduced-motion the token is 0 ms and nothing animates. WAAPI itself needs no style attributes or `<style>` injection. _Corrected in wave 1:_ the CSP is not untouched by this stream, because abcjs's `renderAbc` injects a `<style>` element on every render, which `style-src 'self'` blocks; the fix (a sha256 hash in `style-src`) lands in Stream E (D1). _Rejected:_ a CSS class with `animationend` cleanup (no event at 0 ms).
- **2026-10-07 — The transport is one toggle button (Play/Stop)** so focus stays put when playback starts. It plays the whole song, lights the current note with `is-playing`, sets `ui.playheadNoteId`, and writes `ui.keyboardLights`: the melody note, and the latest chord's tones with its function, kept until the next chord. In hidden mode the chord's function is sent as `"other"` so the keyboard can't reveal the key. Sample loading, failed samples (Retry calls `preload`), and failed playback (Try again) each show a status line.
- **2026-10-07 — The print stylesheet is imported by `Staff.svelte`,** since `App.svelte` and `main.js` are outside this stream. In print it hides everything but the staff (masthead, footer, every other region, the toolbar) and keeps the chip colors with `print-color-adjust: exact`. Print uses the light tokens because the dark theme applies only on screen.
- **2026-10-07 — No unit tests for the ABC writer.** The brief limits tests to `tests/theory/` and the backend, and `tests/` isn't this stream's path. The writer was checked by script against both demo tunes (parsed note count equals note pieces, no abcjs warnings) and in the browser. Proposed as an addition.

## Wave-1 fixes

- **2026-10-07 — Key signature from `K:`, not from the speller (review finding, fixed as proposed).** `keySignature()` now derives the accidentals from the tonic's place on the circle of fifths (minor uses its relative major), exactly what abcjs reads from `K:`, and `abcPitch` writes an explicit accidental whenever the spelled note differs from that. One source of truth for what a bare note means. A theoretical key beyond seven accidentals (G# major, Fb minor; the schema allows those tonics) writes `K:C` with accidentals on the notes, since ABC can't express it. I used a small fifths table rather than Tonal's `Key.majorKey(...).alteration` so the writer has no Tonal dependency of its own (theory stays the only Tonal user).
- **2026-10-07 — D2: hidden mode shows a neutral mark (`•`) for each chord, no letter name.** The accessible name says just "chord". Nothing key-relative: `K:C`, no degrees, no numerals, no function color (the mark is `--ink-muted`).
- **2026-10-07 — D3: the staff shows chord letter names colored by function, like a lead sheet.** No shapes, no chip boxes, no numerals below the staff (those live in D2's chip row). `colorChordSymbols` sets `--chord-color` on each symbol from `functionInfo(fn).color`, preferring the token's `-edge` variant when one exists (yellow `--fn-subdominant` is 1.6:1 as text; its edge is 4.9:1). Tentative mode keeps the full color and sets the letters in italics instead of lowering opacity, which would fail text contrast. Labels in the user's style no longer change the staff's output, but the staff still redraws on a label-style change (D17 is kept as confirmed).
- **2026-10-07 — Chord symbol text is sanitized (review finding, fixed as proposed).** `chordSymbol()` strips `"`, `%`, `\`, and newlines, and anything that doesn't start with a root letter A–G becomes "?", so no chord text can leave its ABC quotes or become an annotation-placement prefix.
- **2026-10-07 — D10: `playWithVisuals` is implemented in `src/staff/playback.js`, and the transport calls it.** A new call stops audio (`stop()`) and takes ownership; the superseded call resolves without touching the drone, playhead, or lights. While it plays it owns `ui.playheadNoteId`, the `is-playing` highlight, and `ui.keyboardLights` with `source: "playback"` (reset at start, so no stale hover chord leaks in; melody neutral, the drone note as melody, chord tones with their function, "other" in hidden mode). At the end it clears the lights only while `source` is still `"playback"`. Chord functions are computed once per play with `chordFunctions` (the same helper the staff uses, so there is one definition), over the `chords` override when one is given. No unit test: the module drives the audio API, the stores, and the SVG highlights, so it isn't one of D6's pure modules; the golden-path smoke covers it.
- **2026-10-07 — D16: abcjs loads on demand** with a "Loading the staff…" status and a retry if the chunk fails; Print is disabled until it loads. The main bundle is now ~100 kB. The lazily loaded abcjs chunk is itself ~509 kB, so Vite still prints its 500 kB warning for that chunk; silencing it needs `vite.config.js` (outside this stream), logged as deferred.
- **2026-10-07 — Keyboard focus survives a redraw (review finding, fixed as proposed).** Before rendering, the staff records the focused note (else the selected note) and its index; afterwards that note keeps the roving tab stop and, if focus was inside the staff, is focused again. If the note was deleted, the note now at its place takes it.
- **2026-10-07 — Arrow keys clamp at both ends (review finding, fixed as proposed).** No wrap: ArrowLeft on the first note and ArrowRight on the last do nothing.
- **2026-10-07 — Redraw when a web font finishes loading (review finding, fixed differently).** With D3 there are no chips measured with `getBBox`, but abcjs itself lays out text with measured metrics, and the 500-weight Jost face loads only once the staff uses it. The staff listens for `document.fonts` `loadingdone` and redraws then, rather than awaiting `document.fonts.ready` once, because the 500 face starts loading only after the first draw has used it.
- **2026-10-07 — Triplets: wave 2.** The comment in `abc.js` and the durations entry above now say what really happens.
- **2026-10-07 — D1 dependency: the CSP fix for abcjs's injected style rule lands in Stream E** (a sha256 hash in `style-src`). No server code changed here. Confirm against main once E has merged: the smoke test asserts zero console errors and the staff renders on load.
- **2026-10-07 — Tests (D6):** `tests/staff/abc.test.js` covers bar splitting, ties, per-bar accidentals, flat minor keys with a flat first in the bar (C minor, F minor), the theoretical-key fallback, hidden mode (`K:C`, neutral mark, no degrees), chord symbol sanitizing, lyric alignment, and the accessible name.
